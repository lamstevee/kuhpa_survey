# 버스 알림 (bus-alert)

퇴근길에 **남부터미널에 도착하면**, 앱을 켜지 않아도 잠금화면에
`461 3분 · 641 곧 · 4319 12분` 이 뜨는 앱입니다.
지도 켜고 정류장 찾아서 새로고침하는 과정을 없애는 게 목적입니다.

Expo(React Native) 앱이라 iOS · Android 둘 다 돌아갑니다.

```
정류장 반경 250m 진입
      ↓  (OS 지오펜스가 앱을 깨움 — 화면 없이도 동작)
알림 시간대인가? · 방금 알렸나?
      ↓  예
서울시 버스도착정보 API 조회 (461 · 641 · 4319)
      ↓
알림 1건 발송
```

## 동작 요약

| | |
|---|---|
| **자동 알림** | 설정한 위치 반경에 들어오면 지오펜스가 앱을 깨워 도착정보를 조회하고 알림을 1건 보냅니다. |
| **시간대 제한** | 기본값 평일 17:00–23:00. 주말·출근길엔 울리지 않습니다. |
| **재알림 방지** | 기본 20분. 정류장 근처를 왔다갔다 해도 알림이 도배되지 않습니다. |
| **직접 보기** | 앱을 열면 20초마다 자동 갱신되는 도착 현황판. 당겨서 새로고침도 됩니다. |
| **여러 정류장** | 461/641/4319가 서로 다른 정류장이면 정류장을 여러 개 등록해도 됩니다. 알림 한 건에 묶여 옵니다. |

도착 시간 색은 "뛰어야 하나"를 기준으로 합니다 — 90초 이하 주황, 4분 이하 노랑, 그 이상 초록.

## 준비물: 공공데이터포털 인증키

1. [data.go.kr](https://www.data.go.kr) 가입
2. **서울특별시_정류소정보조회 서비스** 검색 → **활용신청** (자동 승인, 보통 1분 안에 됨)
3. 마이페이지 → 오픈API → 인증키 복사

앱 설정 화면 1번 칸에 붙여넣고 **연결 테스트**를 누르면 됩니다.
포털이 주는 "인코딩"/"디코딩" 키 중 아무거나 넣어도 앱이 알아서 처리합니다.

> 키는 기기 안(AsyncStorage)에만 저장되고 어디로도 전송되지 않습니다.
> 대신 기기가 잠겨 있어도 백그라운드에서 읽을 수 있어야 해서 암호화 저장소는 쓰지 않았습니다.
> 이 키는 조회 전용 무료 키입니다.

## 내 폰에 설치하기

Expo Go로는 **안 됩니다.** 백그라운드 지오펜스는 네이티브 권한이 필요해서
직접 빌드한 APK를 설치해야 합니다.

### 방법 A — EAS 클라우드 빌드 (안드로이드 스튜디오 없이, 권장)

Expo 계정(무료)만 있으면 됩니다. 빌드는 Expo 서버에서 돌고, 끝나면 APK 다운로드 링크와
QR 코드가 나옵니다. 폰에서 그 QR을 찍어 바로 설치하면 됩니다.

**EAS(Expo Application Services)** 는 Expo가 운영하는 클라우드 빌드 서버입니다.
원래 안드로이드 앱을 만들려면 내 컴퓨터에 Android Studio + JDK + Android SDK(10GB 넘습니다)를
깔아야 하는데, EAS는 그 과정을 Expo 서버에서 대신 돌리고 완성된 APK 링크만 돌려줍니다.
내 컴퓨터엔 Node.js만 있으면 됩니다.

```bash
npm install -g eas-cli   # 최초 1회. CLI 설치

cd bus-alert
npm install

eas login                # expo.dev 계정 (무료)
eas init                 # 프로젝트를 EAS에 연결 (최초 1회, app.json에 projectId가 추가됨)
eas build --platform android --profile preview
```

> 전역 설치가 싫으면 `npx eas-cli@latest login` 처럼 쓰면 됩니다.
> `npx eas` 는 이름이 비슷한 **다른 패키지**를 받아오니 쓰지 마세요.

`eas build`를 처음 돌리면 **"Generate a new Android Keystore?"** 를 묻습니다. **Yes** 하세요.
앱 서명키를 EAS가 만들어서 보관해줍니다 — 직접 관리할 게 없습니다.

`preview` 프로필은 `eas.json`에서 `buildType: "apk"` 로 잡혀 있습니다.
이걸 안 지정하면 EAS가 Play 스토어용 `.aab`를 만들어서 폰에 직접 설치가 안 됩니다.

빌드는 보통 10~20분 걸리고, 끝나면 터미널과 [expo.dev](https://expo.dev) 대시보드 양쪽에
APK 링크가 남습니다.

### 방법 B — 내 컴퓨터에서 APK 뽑기 (계정 없이)

JDK 17과 Android SDK가 깔려 있어야 합니다 (안드로이드 스튜디오를 설치하면 같이 깔립니다).

```bash
cd bus-alert
npm install

npx expo prebuild --platform android --clean
cd android
./gradlew assembleRelease
```

APK 위치:

```
bus-alert/android/app/build/outputs/apk/release/app-release.apk
```

이 파일을 폰으로 옮겨서 설치하면 됩니다. 서명은 디버그 키로 되지만
사이드로드 설치에는 문제 없습니다 (Play 스토어에 올릴 게 아니라면 충분합니다).

USB로 연결돼 있으면 바로 밀어넣어도 됩니다:

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```

### 설치할 때

- 처음 APK를 여는 앱(파일 관리자·크롬 등)에 **"출처를 알 수 없는 앱 설치"** 권한을 한 번 허용해야 합니다.
- 설치 후 앱을 열면 설정 화면이 바로 뜹니다. 아래 "처음 켰을 때 설정 순서"를 따라가세요.
- 위치 권한은 반드시 **'항상 허용'** 으로 주세요. '앱 사용 중에만'이면 알림이 안 옵니다.
- 안드로이드 배터리 최적화가 백그라운드 깨우기를 막는 경우가 있습니다.
  설정 → 앱 → 버스 알림 → 배터리 → **제한 없음**으로 바꿔주세요.

### 아이폰이라면

APK는 안드로이드 전용입니다. iOS는 애플 정책상 사이드로드가 안 되고, 실기기에 올리려면
**애플 개발자 계정**이 필요합니다.

```bash
eas build --platform ios --profile preview   # 개발자 계정 로그인 필요
# 또는 맥 + Xcode 환경에서
npx expo run:ios --device
```

무료 애플 계정으로 Xcode에서 직접 설치하는 것도 되지만, 7일마다 다시 설치해야 합니다.

### 코드 고치면서 개발할 때

```bash
npx expo run:android    # 기기/에뮬레이터 연결 상태에서, 코드 수정이 바로 반영됨
```

검증용:

```bash
npm run typecheck
npm test          # 도착 문구 파싱 · 시간대 판정 단위 테스트
```

## 처음 켰을 때 설정 순서

앱을 처음 열면 설정 화면으로 바로 들어갑니다.

1. **인증키** 붙여넣고 연결 테스트
2. **정류장** — `남부터미널` 로 검색해서 실제로 타는 정류장을 추가합니다.
   추가하면 그 정류장에 오는 노선 중 461·641·4319가 자동으로 선택됩니다.
   방향이 나뉘어 있으면(예: 서초역 방면 / 예술의전당 방면) 타는 쪽 정류장을 고르세요.
   칩을 눌러 노선을 더하거나 뺄 수 있습니다.
3. **알림 위치** — 기본값은 남부터미널역 좌표입니다. 정확히 맞추려면 그 자리에 섰을 때
   **지금 있는 위치로 지정**을 누르세요. 반경은 250m 이상을 권합니다 (아래 참고).
4. **알림 시간대** — 요일과 시간을 퇴근 패턴에 맞춥니다.
5. **권한** — 위치는 반드시 **'항상 허용'** 이어야 앱을 안 켜도 알림이 옵니다.
   '앱 사용 중에만 허용'이면 지오펜스가 등록되지 않습니다.

## 알림이 안 올 때

설정 화면 5번 **기록**에 마지막 40건이 남습니다. 지오펜스가 아예 안 깼는지,
깼는데 시간대/쿨다운에 걸렸는지, 조회가 실패했는지 여기서 구분됩니다.

- **기록이 비어 있다** → 위치 권한이 '항상 허용'인지, 반경이 너무 작지 않은지 확인.
  OS 지오펜스는 셀/와이파이 기반이라 100m 이하는 잘 못 잡습니다. 250~400m를 권합니다.
- **"알림 시간대가 아니라 건너뜀"** → 4번 설정의 요일/시간 확인.
- **"재알림 대기 중"** → 쿨다운. 4번에서 간격을 줄이면 됩니다.
- **"등록되지 않은 인증키"** → 포털에서 활용신청이 승인됐는지 확인 (승인 후 반영까지 몇 분 걸릴 때가 있습니다).
- 안드로이드는 제조사 배터리 최적화가 백그라운드 깨우기를 막는 경우가 있습니다.
  설정 → 배터리 → 이 앱을 **제한 없음**으로 바꿔주세요.

## 알아둘 점

- 서울시 API 서버(`ws.bus.go.kr`)는 https를 지원하지 않습니다.
  그래서 `app.json`에 이 도메인 하나만 대상으로 iOS ATS 예외와 안드로이드 cleartext 를 열어뒀습니다.
- 도착 예측은 서울시가 주는 값 그대로입니다. `출발대기`·`운행종료`처럼 시간이 없는 상태는
  숫자를 만들어내지 않고 그 문구를 그대로 보여줍니다.
- 경기·인천 버스는 이 API에 없습니다. 서울 노선만 조회됩니다.
